# make-the-number

C++ code to resolve challenges posed by https://www.mathsisfun.com/games/make-the-number.html



When I played https://www.mathsisfun.com/games/make-the-number.html, I would sometime get a better solution than the one proposed by the website's "computer".  



Consider the challenge to reach 907 with 8, 3, 6, 2, 100 and 50.  The "computer" was off by 1 (reached 906 or 908) while it was possible to reach 907 with

&#x20;  (100 + 50 + 2) x 6 - 8 + 3



It seemed it could be a fun way to kill time to write some code that performs better.  This is the raison d'etre of this repo.
